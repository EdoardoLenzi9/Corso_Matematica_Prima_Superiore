# 📌 Insieme

## 🚀 Esercizio

$$B=\lbrace2,\ 4,\ 6,\ 8,\ 10\rbrace$$

Trova una proprietà comune che permetta di descrivere tutti e soli gli elementi di $B$.

## 🚀 Esercizio

Costruisci un insieme di **almeno quattro elementi**, non necessariamente numerici, che soddisfi una proprietà comune a tua scelta.

# 📌 Appartenenza ($\in$)

## 🚀 Esercizio

$$A=\{2,4,6,8,10\}$$

stabilisci quali delle seguenti affermazioni sono vere:

- $4\in A$
- $7\in A$
- $10\notin A$
- $3\notin A$

## 🚀 Esercizio

- $x\in\{1,3,5,7,9\}$

- $y\notin\{1,3,5,7,9\}$

# 📌 Uguaglianza tra insiemi

## 🚀 Esercizio

Stabilire se:

$$\{1,2,3\}=\{3,2,1\}$$

Motivare la risposta.

## 🚀 Esercizio

Stabilire se:

$$\{1,2,2,3\}=\{1,2,3\}$$

## 🚀 Esercizio

Spiega perché:

$$\{1,2,3\}\neq\{1,2,4\}$$
